# Profile Dimensions

This file summarizes the key visual assets associated with a personal LinkedIn profile.

Because platform interfaces can change, treat these values as practical working references and verify against current LinkedIn guidance before final production use.

## Profile photo

Use a square image with enough resolution to remain clear on desktop and mobile.

Practical guidance:

- Aspect ratio: 1:1.
- Recommended approach: export a clean square image at high resolution.
- Use a centered crop with comfortable margin around the face.

## Profile background image

Use a wide horizontal image that still works when cropped on smaller screens.

Practical guidance:

- Landscape orientation
- Design with safe space near the center-left and center-right.
- Avoid placing critical text near edges or behind the profile photo area.

## Design notes

- Keep contrast strong enough for text overlays.
- Avoid overly detailed backgrounds that compete with the profile header.
- If adding text, keep it minimal and readable.
- Test how the image appears on both desktop and mobile.
