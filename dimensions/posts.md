# Post Dimensions

This file outlines practical guidance for common LinkedIn post visuals.

## Single-image posts

LinkedIn supports a range of image sizes, but a clean rectangular or square export is usually the easiest to maintain.

Practical guidance:

- Use high-resolution images.
- Keep on-image text large enough for mobile screens.
- Avoid overly dense infographic layouts.

## Carousel and document-style posts

Many LinkedIn creators use slide-based content exported as PDF or image sequences.

Practical guidance:

- Build slides with strong margins.
- Keep each slide focused on one idea.
- Use large headings and minimal copy per frame.

## Link preview visuals

If sharing external content, ensure the destination page has a strong social preview image and metadata.

Practical guidance:

- Use a clear preview image.
- Keep title and description metadata clean.
- Check how the preview renders before publishing if possible.
