# Company Page Checklist

Use this checklist when setting up or reviewing a LinkedIn company page.

## Core setup

- [ ] Company name is correct and consistent with the website.
- [ ] Logo is clear and current.
- [ ] Banner image reflects brand and positioning.
- [ ] Website link is correct.
- [ ] Industry and organization details are filled in accurately.

## Description and positioning

- [ ] Overview explains what the organization does.
- [ ] Description is clear and avoids vague marketing language.
- [ ] Messaging reflects the current brand rather than outdated direction.

## Operational readiness

- [ ] Admin roles are assigned appropriately.
- [ ] Contact details are current where applicable.
- [ ] Featured content or pinned content is current.
- [ ] The page has enough content to avoid looking abandoned.
