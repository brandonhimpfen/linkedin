# Post Checklist

Use this checklist before publishing a standard LinkedIn post.

## Message

- [ ] The post has one clear main idea.
- [ ] The opening line earns attention without feeling manipulative.
- [ ] The post reads well on mobile.
- [ ] The tone matches the audience and subject matter.

## Structure

- [ ] Paragraph breaks improve readability.
- [ ] Claims are grounded and not overstated.
- [ ] Links, if used, are relevant and working.
- [ ] Call to action, if included, feels natural.

## Asset review

- [ ] Any image or document is readable and properly exported.
- [ ] On-image text is large enough for mobile users.
- [ ] Visuals support the message rather than repeat it poorly.

## Final review

- [ ] Spelling and punctuation checked.
- [ ] Names, brands, and references checked.
- [ ] The post is worth publishing and not just filling the feed.
