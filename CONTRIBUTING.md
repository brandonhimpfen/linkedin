# Contributing

Thanks for your interest in contributing.

This repository is intended to be a practical, maintained reference for LinkedIn. Contributions should improve clarity, usefulness, and long-term reliability.

## What kinds of contributions are welcome

- Fixes to dimensions, specs, or outdated platform references.
- Improvements to checklists and workflows.
- New tutorials that are practical and platform-relevant.
- Small scripts or utilities that help with publishing workflows.
- Corrections to broken links or unclear explanations.

## Contribution principles

Please keep contributions aligned with the purpose of the repository.

- Prefer clarity over cleverness.
- Prefer durable guidance over trend-driven advice.
- Keep files focused and easy to scan.
- Avoid promotional content.
- Avoid hype, vague “best practices,” or unsupported claims.
- Use plain, consistent file naming and formatting.

## Content standards

- Use short paragraphs.
- Use headings that describe the content clearly.
- Keep examples practical.
- Do not add large sections of unstructured notes.
- When dimensions or platform behavior may change, avoid overstating certainty.
- When possible, point readers to official LinkedIn documentation in addition to repository guidance.

## File naming

Use lowercase filenames with hyphens.

Examples:

- `company-page.md`
- `post-checklist.md`
- `newsletter-template.md`

## Pull requests

Please make pull requests small and focused when possible.

A strong pull request usually includes:

- a clear title.
- a brief summary of the change.
- a note explaining why the change improves the repository.
