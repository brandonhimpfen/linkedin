# Carousel Post Template

Use this for slide-based LinkedIn document or carousel content.

## Suggested slide structure

1. Title slide with a clear promise
2. Framing slide that explains the problem or topic
3. Main point one
4. Main point two
5. Main point three
6. Example or application
7. Closing summary

## Notes

- Keep one core idea per slide
- Use strong margins and large headings
- Design for quick scanning on desktop and mobile
